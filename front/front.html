业务 Agent 在做什么？

四个面向 PMO 的业务 Agent 分工明确：从 Base 里发现过程数据问题，到风险、督办与管理层汇报一脉相承。 协调与写回策略由内部 Coordinator 编排。

数据事实源：飞书多维表格（Projects / Tasks / Milestones / Risks / FollowUps / WeeklyReports 等）。

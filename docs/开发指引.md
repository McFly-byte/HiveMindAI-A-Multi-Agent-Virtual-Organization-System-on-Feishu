# HiveMindAI 开发指引（当前状态）

本文描述仓库**截至当前合并后的实现范围**、如何本地跑通、以及协作时应注意的边界，便于他人 `git clone` 后继续改代码。

---

## 1. 项目是做什么的

面向飞书 AI 校园挑战赛 MVP：**软件研发 PMO 场景下的多 Agent「虚拟项目办公室」**。业务事实源为飞书多维表格（Base）；Agent Runtime 负责会话与编排，Tool Integration 负责工具注册与执行，Feishu Adapter 封装底层飞书 API（Agent 业务代码不直连 Adapter）。

更完整的边界说明见仓库内 `.cursor/rules/00-project-context.mdc` 等规则文件。

---

## 2. 目录与模块关系（拉代码后先看这些）

| 路径 | 作用 |
|------|------|
| `src/agent_runtime/` | 运行时：配置、Session、事件、`AgentRuntime`、`ToolExecutorProtocol` 等 |
| `src/agent_runtime/mvp/` | MVP 落地：`build_runtime_with_tool_integration`、各 Agent 最小 Handler、`SimpleRuleQualityGate`、`LocalJsonlTraceSink` |
| `src/tool_integration/` | 工具层：`ToolRegistry`、`ToolRuntime`、`ToolIntegrationExecutor`、`scan_tool_dirs` |
| `src/feishu_adapter/` | 飞书 API 工具注册（`register(registry, event_bus=...)`），工具名多为 `feishu_bitable_*` |
| `agents/*/agent.yaml` | 各 Agent 的 `tool_policy.allowed_tools` 等，**须与真实注册工具名一致** |
| `projects/enterprise_rag/` | Demo 项目：`project_state.yaml`、`table_manifest.yaml`（表 ID 等多为 `${FEISHU_*}` 占位） |
| `tool_integrations/` | 扩展工具（如 `trace_tool.py`），与 `src/feishu_adapter` 一并被默认扫描 |
| `scripts/run_mvp_demo_chain.py` | MVP 链式演示：秘书 → 风险 → 追问 → 周报 → 协调（可选写回） |
| `tests/` | 单测；`conftest.py` 会把 `src` 加入 `sys.path` |

历史变更片段可参考 `docs/changes/05-04-lmc-agent-runtime.md`。

## 3. 环境与依赖

- **Python**：建议 **3.11+**（与 `uv.lock` / `pyproject.toml` 中 `requires-python` 一致）。
- **安装依赖**：务必用「将要运行脚本的同一个解释器」安装，避免 `pip` 与 `python` 不一致：

  ```bash
  python -m pip install -r requirements.txt
  # 或开发可编辑安装
  python -m pip install -e .
  ```

- **根目录 `pyproject.toml`**：声明了 `pydantic`、`PyYAML`、`lark-oapi` 等；若使用 `uv`，可在本机执行 `uv sync`（需已安装 `uv`）。

## 4. 飞书与 Base 配置（`.env`）

1. 在仓库**根目录**创建 **`.env`**（已被 `.gitignore` 忽略，**不要提交** App Secret / Token）。
2. 至少需要：
   - **`FEISHU_APP_ID`**、**`FEISHU_APP_SECRET`**：应用凭证。
   - **`FEISHU_BASE_APP_TOKEN`**：多维表格应用 `app_token`（与 `projects/enterprise_rag/project_state.yaml` 中占位对应）。
   - **`FEISHU_TABLE_PROJECTS`**、**`FEISHU_TABLE_TASKS`** 等：与 `projects/enterprise_rag/table_manifest.yaml` 里 `${FEISHU_TABLE_*}` 一致。

脚本在检查缺失变量前会调用 `load_dotenv_if_present` 加载根目录 `.env`。更严格的校验逻辑在 `src/agent_runtime/mvp/project_env.py` 的 `feishu_demo_chain_env_missing`（含展开后 `base_app_token` / 各表 `table_id` 是否为空）。

**IM WebSocket**：`feishu_adapter/feishu_message_tools.py` 在注册时**默认不再**启动长连接，避免与 `asyncio.run()` 主链路冲突（曾出现 `This event loop is already running`）。若确实需要 IM 事件流，设置 **`FEISHU_ENABLE_IM_WS=1`**（或 `true` / `yes`）。

**工具扫描目录**：未设置 `HIVEMIND_TOOL_SCAN_DIRS` 时，默认会扫描已存在的 `src/feishu_adapter` 与 `tool_integrations`（见 `src/tool_integration/loader.py`）。

## 5. 如何运行

### 5.1 测试

```bash
python -m pytest tests/ -q
```

部分异步相关用例使用 `asyncio.run` 包装，**不要求**必须安装 `pytest-asyncio`（以当前仓库为准）。

### 5.2 MVP 演示链

```bash
python scripts/run_mvp_demo_chain.py
# 不写回 Base 中协调器提议时：
python scripts/run_mvp_demo_chain.py --skip-coordinator-write
```

缺环境变量时会 **退出码 2** 并打印中文说明，而不是未捕获栈崩溃。

### 5.3 协调器写回与 Quality Gate

- 业务子 Agent 只产出 **proposed** 结构；**写回**由 **Coordinator** 在通过 **Quality Gate**（当前为 `SimpleRuleQualityGate`）后调用 **`feishu_bitable_create_record`** 等工具完成。
- Demo 脚本里写 `AgentRuns` 的字段名需与你方 Base 列名一致；若不一致请在脚本或 manifest 侧调整。

## 6. 当前实现与刻意未做的范围

**已实现（MVP）**

- `ToolIntegrationExecutor` 实现 `ToolExecutorProtocol`，`call_tool` 会把 `ToolCallRecord` 写入 `AgentSession.steps`。
- `build_runtime_with_tool_integration` 组装 `AgentRuntime` + 执行器 + MVP Registry/Handlers。
- 五个 Agent 的最小 Handler（读 Base / 结构化输出 / 协调写回路径）。
- `AgentCallRequest.input_payload` 与 `session.memory` 中落盘各步输出，便于链式传递。

**未纳入或勿在此仓库扩展（与规则一致）**

- 不在此重写整套 Feishu Adapter 业务逻辑；子 Agent 不直连 Adapter。
- 不引入 LangGraph / CrewAI 等编排框架；不做完整聊天式前端。
- 不在代码中写死 token / secret。

## 7. 协作时建议的自检清单

1. 修改 `agents/*/agent.yaml` 后：确认 **`allowed_tools` / `denied_tools`** 与 `ToolRegistry` 中实际工具名一致。
2. 修改 manifest 占位符后：同步更新 **`.env`** 与文档/示例（勿把真实密钥提交进 Git）。
3. 新增需随注册加载的工具：放在 `tool_integrations/*.py` 或 `src/feishu_adapter` 中并实现 `register(registry, **kwargs)`。
4. 提交前：`python -m pytest tests/`；若测试未全绿，在 **commit message / PR 说明** 中写明原因与后续计划，避免误导为已验收。

## 8. 常见问题

| 现象 | 可能原因 |
|------|----------|
| `ModuleNotFoundError: pydantic` | 依赖未装到当前 `python` 对应环境，请用 `python -m pip install ...` |
| `base_app_token is empty` | `.env` 未配置或未加载 `FEISHU_BASE_APP_TOKEN` |
| `event loop is already running`（Lark） | 已默认关闭 IM WS；若自行打开 `FEISHU_ENABLE_IM_WS`，避免在 `asyncio.run` 内嵌套冲突用法 |
